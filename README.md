# Báo cáo tồn kho – Kho của tôi

Trang xem 10 báo cáo của module Kho: công thức từng ô, câu SQL tương ứng, ghi chú theo ô.

- Mở `index.html` (hoặc link GitHub Pages) để xem.
- Truy cập giới hạn cho người được mời (vai trò `reader`, đăng nhập tài khoản `@nbc.com.vn`). Cách thêm/xóa người dùng: xem [docs/ACCESS-CONTROL.md](docs/ACCESS-CONTROL.md).
- Ghi chú lưu trên trình duyệt và, nếu đã cấu hình `SHEET_URL` trong `index.html`, đồng bộ lên Google Sheet.
